# پنل عمومی فقط خواندنی روی پورت 1000

این نسخه صفحه ورود را حذف می‌کند و داشبورد را بدون ورود نمایش می‌دهد. دکمه‌های تأیید خرید و ثبت پرداخت برداشت حذف شده‌اند. APIهای تغییردهنده Backend همچنان باید نشست ادمین را الزامی کنند.

## نصب
1. فایل‌های این بسته را در پوشه سرویس پنل (`~/panel/ecgpa`) جایگزین کنید.
2. Backend را نیز با فایل `core/admin_dashboard.py` از بسته `POLIFY_public_readonly_backend.zip` به‌روزرسانی کنید.
3. سرویس پنل را بسازید:
   `docker compose up -d --build`
4. پنل: `http://SERVER_IP:1000`

## هشدار
این داشبورد عمومی است. اطلاعات مستقیم هویتی مانند Telegram ID، نام کاربری، آدرس کیف پول، اطلاعات تماس و هش تراکنش‌ها از پاسخ عمومی حذف شده‌اند؛ اما آمار و مقادیر مالی تجمیعی و رکوردهای مالی همچنان قابل مشاهده‌اند. اگر نمی‌خواهید حتی مبالغ و رکوردهای مالی عمومی باشند، این سرویس را روی اینترنت عمومی منتشر نکنید یا دسترسی شبکه را محدود کنید.
